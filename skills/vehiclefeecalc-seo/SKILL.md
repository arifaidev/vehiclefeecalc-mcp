# VehicleFeeCalc SEO

## Purpose
Use this skill when creating, updating, or reviewing SEO content for VehicleFeeCalc.com.

## Search-intent model
Match the page to the user's calculation intent. Typical intents include:
- vehicle registration fee
- title transfer cost
- vehicle sales/use tax
- back registration fees and penalties
- out-the-door vehicle cost
- EV registration surcharge

Do not create a generic page when a specialized calculator already satisfies the intent.

## Content requirements
- Explain what the calculator includes and excludes.
- Show the important inputs.
- Explain the calculation at a useful level without inventing state rules.
- Link to the relevant state calculator and supporting pages.
- Make estimates clearly identifiable as estimates.
- Keep fee facts aligned with verified data.

## Programmatic pages
For state pages:
- Keep the template consistent.
- Inject only state-specific facts.
- Never copy another state's fee formula into a new page.
- Include source/verification information when the site template supports it.
- Avoid doorway-page duplication.

## On-page quality
Use descriptive titles and headings, concise introductions, useful FAQs, and clear calls to action. Prefer natural language over keyword stuffing.

## Accuracy rule
SEO copy must never override calculator correctness. If a marketing statement conflicts with verified calculation logic, flag it for review.
